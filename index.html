About

I'm a software engineer who works where cybersecurity and full-stack development meet. Since August 2023 I've been at Discern Security, working across the frontend, backend, cloud infrastructure and DevOps of a security controls management platform. Discern connects to the security tools a company already owns, measures how well each one is configured, and shows teams what to fix first.

Work at Discern Security

The systems I've designed, built and documented, grouped by the two sides of my work: securing the platform and the identities that use it, and engineering the product from end to end.

Cybersecurity engineering

Enterprise single sign-on

Identity and access

Enterprise customers expect to sign in with the identity provider they already run. I built single sign-on so teams reach the platform with their corporate accounts, under their own access policies, with support for both Microsoft Entra ID and Okta so customers aren't tied to a single vendor.

  • Built the sign-in flow with Microsoft Entra ID, then added an Okta identity provider connection, including how identity attributes from each are read and trusted.
  • Wrote the customer-facing Microsoft Entra SSO configuration guide, so admins can set it up without a support call.

Result: Customers sign in with the identity provider they already use, Microsoft Entra ID or Okta, and admins can set it up themselves from the guide.

  • Microsoft Entra ID
  • Okta
  • SSO
  • Technical writing

Just-in-time user provisioning

Identity and access

Creating every user by hand doesn't scale for large organisations. With just-in-time provisioning, an account is created the first time someone signs in through their identity provider, using the details that provider sends.

  • Implemented first-login account creation from the claims Microsoft Entra ID sends at sign-in.
  • Documented the JIT setup and behaviour in the Microsoft Entra SSO configuration guide.

Result: New users get access on their first sign-in, without an admin creating each account by hand.

  • JIT provisioning
  • Microsoft Entra ID
  • Identity claims

EDR security tool integrations

Endpoint security

Discern's value depends on reading configuration from the security tools customers already use. I built and maintained the endpoint detection and response (EDR) connectors that pull policy and configuration data from those products and normalise it, so different vendors can be compared and scored the same way.

  • Built integrations with CrowdStrike Falcon and SentinelOne through their vendor APIs.
  • Mapped each vendor's settings into a shared data model used for scoring and recommendations.

Result: CrowdStrike and SentinelOne deployments are scored on the same scale, so customers can compare and improve them side by side.

  • CrowdStrike
  • SentinelOne
  • EDR
  • REST APIs

Cloud data pipelines

Data and cloud

Raw configuration data has to be cleaned and transformed before it can drive scores, framework mappings and reports. I worked on ETL pipelines on AWS that turn collected data into the datasets the platform runs on.

  • Land raw data in Amazon S3 and transform it with AWS Glue jobs, triggered by AWS Lambda.
  • Load processed data into Amazon Redshift for reporting, and query it ad hoc with Amazon Athena.
  • Run containerised services on Amazon ECS.

Result: Data collected from customer tools becomes reliable, queryable datasets for scoring and reporting.

  • AWS Glue
  • S3
  • Lambda
  • Redshift
  • Athena
  • ECS
